Quick start THREE WAYS TO MAKE A GAME

1 · Write a scene (no code)

Open the Scene editor (; or { }), pick Blank 2D scene, edit the YAML and press Run (Ctrl/⌘ Enter). Save as sheet adds it as a tab in this browser.

2 · Snapshot, then edit

On any sheet, press Snapshot in the Scene editor. The running world is written out as YAML (bodies, joints, camera). Change it and Run it as a new sheet.

3 · Write JavaScript

For anything the scene language can't express, add one Engine.register({...}) block (see JavaScript sheets), or put JavaScript in a scene's script: hooks.

Tune feel + look

Settings (,) changes every physics constant and art-style token live. Copy JSON exports them for a prompt or another file.

Prompting tip: give an AI this file (or just this Docs page) and ask for "a YAML scene for <game idea>". Paste the answer into the Scene editor and press Run. A-05 Pinball, B-05 Bowling, B-06 Expedition and B-07 Quarry are written entirely in YAML, so open them in the editor as worked examples. Hold Backspace (or the ◀◀ button) on any sheet to rewind time.

Scene language YAML · ONE FILE PER SHEET · COMPILES TO A PLAYABLE DEMO

scene:
  id: knock          # unique id (also the URL #anchor)
  title: Knockdown
  dim: 2             # 2 or 3
  about: Topple ten of fifteen crates with one kick.
  controls: [[Space, kick]]
camera: {fit: [-10, -1, 10, 10]}          # 2D: frame a rectangle
bodies:
  - {type: static, shape: box, size: [20, 1], pos: [0, -0.5]}
  - {name: ball, shape: circle, r: 0.5, density: 4, pos: [-7, 1], style: {accent: true}}
  - {tag: crate, shape: box, size: [0.9, 0.9], pos: [2, 0.45],
     grid: {count: [3, 5], spacing: [1.5, 0.9]}}       # generator → 3 towers, 15 bodies
rules:
  - on: key Space
    do: [push ball [12, 6], sfx launch]          # velocity change in m/s; aim high to topple
  - on: when count('tag:crate', 'fallen') >= 10
    do: [win "Ten down" "in ${t} s"]
hud:
  FALLEN: =count('tag:crate', 'fallen')
Top-level keyWhat it holds
sceneid title code dim tag about controls touch grab pan zoom seed impacts. controls: [[key, what]], touch: [{key, label}] (on-screen buttons on phones), grab: false turns off drag-to-grab, seed fixes the random seed.
camera2D: x y zoom, fit: [x0, y0, x1, y1], follow: SEL, lead (s), offsetY. 3D: target yaw pitch (degrees) dist min max, follow: SEL, offset.
worldgravity substeps jointIterations allowSleep. Keys given here win over Settings for this sheet.
materialsNamed field sets; a body with material: wood merges them in first.
templatesNamed body specs for the spawn action (or template: name on a body).
bodiesList of body specs, each optionally multiplied by one generator.
jointsList of joints between named bodies (or world).
character3D only: a walking player (kinematic capsule) driven by WASD/arrows relative to the camera, Shift to run, Space to jump. See Terrain, character, ragdolls.
rulesEvent → actions: the game logic.
hudLabel → value or =expression, refreshed every step.
annotateDrafting overlay: dimensions, callouts, text, lines.
scriptOptional JavaScript hooks: setup step after draw.

YAML subset: maps and lists by indentation, - key: v list items, flow [a, b] / {k: v}, quoted or plain strings, numbers, booleans, null, # comments, and | / > block text. Errors name the line, and the editor selects it. Units are metres, kilograms and seconds. Angles in scenes are degrees; angular velocities are rad/s. +Y is up.

Every body also takes name tag type (dynamic, static or kinematic) pos, angle (2D, degrees) or rot: [x, y, z] (3D, degrees) or q, vel w density mass friction restitution rolling linearDamping angularDamping gravityScale fixedRotation sensor noSleep awake layer mask group bullet (bullet: true sweeps the body from its start to end pose every step, so it cannot tunnel), and style: {accent, hatch, ghost, hidden, fill: none, stroke: false}. Any value can be an =expression. Sensors draw dashed in 2D; in 3D they are invisible unless you give them a style.

character: {pos: [0, 1.2, 4], speed: 4.5, run: 8, jump: 6.5, stepHeight: 0.4, maxSlope: 48}

     height: "5*fbm(x*0.03, z*0.03)*smoothstep(9, 26, hypot(x, z))"}
  - {tag: rock, shape: rock, size: [1.2, 0.8, 1], scatter: {count: 20, min: [-30, 9, -30], max: [30, 9, 30]}}

rules:
  - {on: key F, do: [fire pellet 70]}
  - {on: key C, do: [checkpoint]}
  - {on: key V, do: [restore]}
  • character creates a kinematic capsule named player (or name). It slides along walls, steps up ledges up to stepHeight, refuses slopes steeper than maxSlope (degrees), snaps down stairs, rides moving platforms and shoves bodies lighter than pushMass (kg, default 60). The camera follows it; right-drag orbits. Other fields: radius height style.
  • ragdoll on a body spec builds an 11-part humanoid (pelvis, torso, head, upper/fore arms, thighs, shins) with cone-twist and hinge joints. Parts are named doll.head, doll.thighL …; with a generator, doll1.head …. Options: scale density friction; pos is the pelvis.
  • heightfield renders with contour lines (0.5 m minor, 2.5 m major). Build it before anything that calls height().
  • Rewind works on every sheet: hold Backspace or the ◀◀ button. The last 15 s of physics and game state (score, variables, rule state) are recorded.

Writing + saving

  • Snapshot writes the running world as YAML: every body (shape, pose, velocity, material, style) and joint, plus camera and world. YAML sheets keep their rules, HUD and annotations. JavaScript sheets export bodies and joints only.
  • Run compiles the text and loads it as a tab; errors show the line and select it. Save as sheet keeps it in this browser. Delete saved sheet removes it.
  • To ship a scene inside the file, add it as <script type="text/yaml" data-scene>…</script> before the main script. Every block found there becomes a tab at start-up.
  • In code: Scene.register(text) adds a sheet, Scene.snapshot(Engine.g) returns YAML, and YAML.parse / YAML.stringify are available for your own data.

JavaScript sheets FULL CONTROL · ONE CALL

Engine.register({
  id: 'flipper', dim: 2, code: 'A-06', title: 'Flipper', tag: 'Arcade',
  about: 'One sentence a player reads first.',
  controls: [['Z / M', 'flippers']],
  touch: [{ key: 'KeyZ', label: 'Left' }, { key: 'KeyM', label: 'Right' }],
  grab: false,                      // engine drag-to-grab on/off
  cam: { x: 0, y: 6, zoom: 40 },    // 2D camera · 3D uses orbit: {target, yaw, pitch, dist}
  setup(g) {                        // g.world, g.rng, g.noise, g.view, g.state
    const W = g.world;
    W.add({ type: 'static', shape: Shape2.box(20, 1), pos: v2(0, -0.5) });
    const flip = W.add({ shape: Shape2.capsule(1, 0.15), pos: v2(-2, 1) });
    g.state.flip = W.revolute(null, flip, v2(-3, 1), { motor: true, motorSpeed: 0, maxMotorTorque: 400, limits: true, lower: -0.5, upper: 0.5 });
    g.state.ball = W.add({ shape: Shape2.circle(0.3), pos: v2(-1, 8), restitution: 0.6 });
  },
  step(g, dt) {                     // fixed 60 Hz, before physics
    g.state.flip.o.motorSpeed = g.input.key('KeyZ') ? 20 : -10;
  },
  after(g) {                        // read g.world.events.begin / .end / .sensorBegin
    g.hud('HEIGHT', g.state.ball.pos.y.toFixed(1));
    if (g.state.ball.pos.y < -5) g.banner('Ball lost', 'Try again', 'lose');
  },
  draw(g) {                         // drafting overlay
    g.view.dim(v2(-10, 0), v2(10, 0), -0.6);
  },
});

Hooks: setup(g) builds the world · step(g, dt) fixed-rate logic before physics · after(g, dt) after physics (read g.world.events) · frame(g, dt) per rendered frame (cameras) · draw(g) overlays · pointer(g, input) return true to take pointer input from the engine.

Tuning

SymptomChange
Long chains or ropes stretch under heavy loadsnew World2D({ substeps: 6 }). Joint stiffness follows the substep rate (¼ of it).
Heavy object sinks into a light oneMore substeps; keep mass ratios under about 100:1 where you can.
Balls and capsules roll foreverrolling: 0.02 on the body (metres of rolling resistance).
Piles never sleepPHYS.linSleep / angSleep thresholds, or add damping.
Bodies pass through each other at extreme speedSpeculative margins grow with speed; for thin, fast or spinning projectiles add bullet: true (swept every step).
Ragdolls are too floppy / too stiffragdoll: {friction: 3} (joint damping, N·m); more substeps make the joints stiffer.
Character snags on small bumpsRaise stepHeight; lower maxSlope to stop it climbing hills.
